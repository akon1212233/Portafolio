💻 ¿Qué dice tu portafolio de ti?

¿Alguna vez has pensado en lo que tu portafolio dice de ti como desarrollador o desarrolladora?

Tu portafolio será mucho más que una página web: será tu carta de presentación profesional, un espacio donde podrás mostrar lo que has aprendido, los proyectos que has desarrollado y tu evolución durante este proceso de formación.

Hasta ahora hemos trabajado con HTML, CSS, JavaScript, Git y GitHub, y este proyecto será una oportunidad para integrar todo lo aprendido y transformarlo en una experiencia web creada por ti.

Además, este portafolio no será un proyecto que termine aquí. A medida que avances en tu carrera, podrás incorporar nuevos conocimientos, proyectos, tecnologías y experiencias. Tu portafolio debe crecer contigo.

🎯 Objetivo del proyecto

Crear un portafolio web profesional, responsivo, visualmente atractivo e interactivo, que permita presentar quién eres, qué sabes hacer y los proyectos que has desarrollado.

La idea es que este portafolio pueda ser utilizado posteriormente como parte de tu presentación profesional y búsqueda de oportunidades laborales o de práctica.

📅 Fecha de entrega

30 de Octubre 2026

La entrega debe realizarse dentro del plazo establecido.

🐙 1. Repositorio exclusivo en GitHub

Debes crear un repositorio específico en GitHub para tu portafolio.

No debes utilizar el repositorio de otro proyecto para esta entrega.

El repositorio deberá contener todos los archivos necesarios para que tu portafolio pueda ser ejecutado y posteriormente publicado utilizando GitHub Pages.

Además, tu portafolio debe estar vinculado con tu trabajo realizado anteriormente en GitHub.

🌐 2. Tu portafolio debe incluir

El diseño y la estructura son libres. Puedes utilizar tu creatividad y desarrollar una propuesta que represente tu personalidad como futuro/a desarrollador/a.

Sin embargo, debe cumplir como mínimo con los siguientes elementos:

👤 Presentación personal

Incluye información que permita conocerte profesionalmente. Por ejemplo:

Nombre.
Breve descripción o presentación.
Perfil como desarrollador/a.
Intereses profesionales.
Tecnologías o habilidades que estás desarrollando.
🧰 Tecnologías y habilidades

Presenta las tecnologías que has aprendido y/o utilizado durante Skillnest.

Puedes incluir, por ejemplo:

HTML · CSS · JavaScript · Git · GitHub

Si has trabajado con otras tecnologías o herramientas, también puedes incorporarlas.

📂 Proyectos

Debes mostrar algunos de los proyectos que hayas desarrollado.

Cada proyecto debería incluir información como:

Nombre del proyecto.
Descripción breve.
Tecnologías utilizadas.
Imagen, captura o elemento visual.
Enlace al proyecto cuando corresponda.
Enlace al repositorio de GitHub.

El portafolio debe permitir que otra persona pueda explorar tu trabajo y conocer cómo has aprendido y construido tus proyectos.

📝 Tareas y trabajos adicionales

También puedes incorporar tareas, ejercicios o proyectos adicionales que consideres relevantes para demostrar tus habilidades.

No tienes que limitarte únicamente a los proyectos realizados durante las clases.

💼 3. Identidad profesional

Tu portafolio debe comenzar a formar parte de tu identidad profesional.

Por esta razón, debes crear o utilizar:

🔗 LinkedIn

Debes contar con un perfil de LinkedIn que puedas asociar directamente a tu portafolio.

Incluye un enlace visible desde tu página hacia tu perfil de LinkedIn.

📧 Correo profesional de contacto

Debes disponer de un correo electrónico de contacto que puedas utilizar para recibir comunicaciones profesionales.

Este correo debe aparecer de manera clara en tu portafolio para que una persona interesada en tu trabajo pueda contactarte.

🎨 4. Diseño y experiencia de usuario

El diseño es completamente libre, pero tu página debe presentar un aspecto estéticamente profesional y coherente.

No buscamos que todos los portafolios sean iguales. Al contrario, queremos que cada uno tenga su propia identidad.

Puedes trabajar con:

Tipografías.
Colores.
Animaciones.
Transiciones.
Ilustraciones.
Imágenes.
Tarjetas.
Secciones interactivas.
Menús dinámicos.
Efectos visuales.

La creatividad es parte de la evaluación.

📱 5. Diseño responsivo

Tu portafolio debe funcionar correctamente en diferentes tamaños de pantalla.

Debe poder visualizarse adecuadamente, al menos, en:

💻 Computador
📱 Teléfono móvil
📲 Tablet

No basta con que la página se vea bien solamente en tu computador.

🎬 6. Incorporación de video

Tu portafolio debe incluir al menos un video.

El video puede utilizarse, por ejemplo, para:

Presentarte.
Mostrar un proyecto.
Explicar una funcionalidad.
Presentar tu proceso de aprendizaje.
Mostrar una demostración de alguna aplicación.

La incorporación del video debe tener sentido dentro del diseño del sitio.

⚡ 7. JavaScript e interacción

Tu portafolio debe demostrar que sabes utilizar JavaScript para generar interacción y comportamiento dinámico.

No queremos solamente una página estática.

Debes incorporar al menos algunos efectos o funcionalidades dinámicas mediante manipulación del DOM y/o eventos con JavaScript.

Por ejemplo:

Menú de navegación dinámico.
Botones interactivos.
Cambio de contenido.
Modal o ventana emergente.
Mostrar/ocultar información.
Animaciones activadas por interacción.
Cambio de tema.
Filtros de proyectos.
Galerías.
Efectos al hacer scroll.
Formularios interactivos.
Contadores.
Elementos que reaccionen a eventos del usuario.

La idea es demostrar que JavaScript forma parte real de tu página y no solamente está incluido en el proyecto.

🧠 8. Utiliza lo aprendido en Skillnest

Este proyecto debe ser una oportunidad para integrar los conocimientos adquiridos durante el curso.

Utiliza los recursos y herramientas que has aprendido en:

HTML + CSS + JavaScript + Git + GitHub

No se trata simplemente de copiar una plantilla y cambiar el contenido.

Tu objetivo es construir una página que permita demostrar lo que sabes hacer actualmente.

🌟 Algunas recomendaciones

Tu portafolio representa tu proceso actual de aprendizaje. No necesitas demostrar que lo sabes todo.

La idea es mostrar lo que has aprendido, lo que eres capaz de construir y hacia dónde quieres seguir creciendo.

🎨 Hazlo tuyo

No todos los portafolios tienen que verse iguales.

Atrévete a experimentar, probar diseños y construir una propuesta que realmente te represente.

Pregúntate:
